## GitHub Pages로 배포

1. 이 폴더의 파일을 저장소 맨 위(root)에 올립니다. `.nojekyll`도 함께 올립니다.
2. 저장소 Settings → Pages → Build and deployment → Source: **Deploy from a branch**
3. Branch: **main**, 폴더: **/(root)** → Save
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.
